# Paleta de marca — Cromática Creativa

Derivada muestreando los píxeles reales del isotipo `favicon-cc.png` (una "C" con
un degradado tipo arcoíris). Fuente de verdad de color para el panel administrativo
(Strapi) y futuros clientes.

## Color principal (interactivo)

`#7C3AED` — violeta profundo de la familia del isotipo. Se usa en botones, enlaces,
foco y estados activos. Contraste con texto blanco ≈ 5.7:1 (AA para texto normal).

- Principal: `#7C3AED`
- Hover / activo: `#6D28D9`
- Fondo suave (selección/hover sutil): `#EDE9FE`

## Paleta secundaria (identidad, detalles decorativos)

Tonos muestreados del isotipo, para acentos donde el diseño lo permita. Usar una
selección reducida (4–6) sobre fondo claro, con saturación moderada.

| Tono | Hex | Matiz aprox. |
| --- | --- | --- |
| Rosa | `#F3288D` | ~330 |
| Magenta | `#DA40CF` | ~300 |
| Violeta | `#A469E0` | ~270 |
| Azul | `#5FA5F0` | ~210 |
| Cian | `#61CDD6` | ~180 |
| Verde | `#8FD152` | ~100 |
| Amarillo | `#EBD92E` | ~60 |

## Uso recomendado

- Acciones primarias (guardar, agregar, inicializar): principal `#7C3AED`, hover `#6D28D9`.
- Foco visible: anillo `rgba(124,58,237,.18)` sobre borde `#7C3AED`.
- Acciones destructivas: rojo del sistema (no de esta paleta) para diferenciar.
- Texto sobre principal: blanco (contraste AA).
- Los tonos secundarios son decorativos; no usarlos como fondo de texto pequeño
  sin verificar contraste.
